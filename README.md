# MineColonyReborn

MineColonyReborn is a Minecraft plugin that recreates the essence of the popular mod MineColony. It allows players to create a camp structure by placing a campfire, which spawns a basic camp with a chest containing food and other essential items. The plugin is designed to be simple and lightweight, focusing on the core mechanics of MineColony.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Players will automatically receive a camp item upon joining the server.
2. To place the camp structure, right-click with the camp item to place a campfire.
3. Admins can give themselves a camp item using the command `/colonie give camp`.
